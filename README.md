# LAN File Share

同じローカルネットワーク（LAN）に接続している端末同士で、パスワード付きのファイル共有ができるPython製ツールです。

ホスト側で共有フォルダとパスワードを設定してサーバーを起動すると、アクセス用URLとQRコードが表示されます。受信側はスマートフォンやPCのブラウザからアクセスし、パスワードを入力するだけでファイルを一覧表示・ダウンロードできます。

## 主な機能

-   共有するフォルダを起動時に指定
-   共有用パスワードを設定
-   LAN内でアクセスするためのURLを表示
-   URLを含むQRコードをターミナルに表示
-   ブラウザでパスワード認証
-   共有フォルダ直下のファイル一覧を表示
-   ファイル名とファイルサイズを表示
-   選択したファイルをダウンロード
-   認証後のログアウトに対応

[こちら](https://github.com/nullpus/LanFileShare/releases/latest/download/lan_file_share.py)からやってください！

## 動作環境

-   Python 3.10以降を推奨
-   Windows / macOS / Linux
-   ホスト端末とアクセス端末が同じローカルネットワークに接続されていること

## インストール

### 1. Pythonをインストール

Pythonがインストールされていない場合は、[Python公式サイト](https://www.python.org/downloads/)からインストールしてください。

### 2. 必要なライブラリをインストール

ターミナルまたはコマンドプロンプトで次を実行します。

``` bash
python -m pip install flask "qrcode[pil]"
```

## 起動方法

`lan_file_share.py` を保存したフォルダで、次のコマンドを実行します。

``` bash
python lan_file_share.py
```

起動すると、共有するフォルダのパスとパスワードを順番に尋ねられます。

``` text
公開するフォルダのパスを入力してください:
C:\Users\User\Desktop\共有

共有用パスワードを設定してください（8文字以上推奨）:
パスワードをもう一度入力してください:
```

パスワードは入力中に画面へ表示されません。

設定が完了すると、アクセス用URL、共有パスワード、QRコードがターミナルに表示されます。

## 使い方

### ホスト側

1.  共有したいファイルを1つのフォルダにまとめます。
2.  `lan_file_share.py` を起動します。
3.  共有フォルダのパスを入力します。
4.  共有用パスワードを2回入力します。
5.  表示されたQRコードとパスワードを、共有相手に伝えます。
6.  共有を終了するときは、ターミナルで `Ctrl+C` を押します。

### ダウンロードする側

1.  ホスト側と同じWi-FiまたはLANに接続します。
2.  スマートフォンのカメラなどでQRコードを読み取ります。
3.  ブラウザで表示されたページに共有パスワードを入力します。
4.  ファイル一覧から必要なファイルの「ダウンロード」を選びます。

専用アプリのインストールは不要です。

## 設定・仕様

  項目           内容
  -------------- ----------------------------------
  Webサーバー    Flask
  接続ポート     `8000`
  待受アドレス   `0.0.0.0`
  認証           パスワード認証・セッションCookie
  公開対象       指定フォルダ直下の通常ファイル
  QRコード       ターミナル上に表示
  ファイル転送   ブラウザからダウンロード

## セキュリティ上の注意

-   このツールは、信頼できるローカルネットワーク内での一時的なファイル共有を想定しています。
-   インターネットへ直接公開しないでください。ルーターのポート転送も設定しないでください。
-   ホスト側のファイアウォールで通信を許可する場合は、信頼できるプライベートネットワークに限定してください。
-   パスワードは第三者に知られないように管理してください。
-   HTTP通信のため、同じネットワーク内で通信を監視できる人に内容を見られる可能性があります。機密性の高いファイルの共有には使用しないでください。
-   共有中はホスト側のPCを起動したままにしてください。
-   共有を終了するには、ホスト側で `Ctrl+C` を押してください。

## 現在の制限

-   共有対象は指定フォルダの直下にあるファイルのみです。サブフォルダ内のファイルは一覧に表示されません。
-   隠しファイル、シンボリックリンク、フォルダは共有対象外です。
-   ファイルのアップロード機能はありません。
-   複数ファイルの一括ダウンロード機能はありません。
-   パスワードはサーバー起動ごとに設定します。

## トラブルシューティング

### QRコードを読み取っても接続できない

-   ホスト側とアクセス側が同じネットワークに接続されているか確認してください。
-   ホスト側のPythonプログラムが起動中か確認してください。
-   ホスト側のファイアウォールで、プライベートネットワーク上のTCPポート
    `8000` への接続が許可されているか確認してください。
-   ゲストWi-Fiやネットワーク分離機能によって、端末同士の通信が禁止されていないか確認してください。

### パスワードが通らない

-   ホスト側に表示されたパスワードと同じものを入力してください。
-   大文字・小文字や記号の違いに注意してください。

### `ModuleNotFoundError` が表示される

必要なライブラリを再度インストールしてください。

``` bash
python -m pip install flask "qrcode[pil]"
```
